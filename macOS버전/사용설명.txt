Vitract — Mac용 영상 다운로드·스크립트 추출 앱

실행 방법
Finder 문서 > 영상제작 APP 폴더의 ‘Vitract.app’을 더블클릭합니다.
실제 앱은 macOS버전/build/Vitract.app에 보존되어 있으며 최상위 앱은 바로가기입니다.
1. 영상 게시물 링크를 붙여넣고 ‘영상 확인’을 누릅니다.
2. 영상 제목을 확인하고 원하는 화질을 선택합니다.
3. 필요하면 저장 위치를 변경한 뒤 ‘MP4 저장’을 누릅니다.
4. 완료되면 ‘Finder에서 보기’로 저장한 파일을 확인합니다.

기본 저장 위치: 다운로드 > 영상저장 (기존 저장 위치 유지)
영상과 오디오를 하나의 MP4 파일로 저장합니다. 필요한 경우 H.264/AAC로
변환하므로 고화질·긴 영상은 다운로드 이후 변환 시간이 더 필요합니다.
같은 이름의 파일이 이미 있으면 별도 이름으로 저장합니다.
다운로드와 변환은 ‘취소’ 버튼으로 중단할 수 있습니다.

지원 범위
YouTube·Shorts 및 Instagram·Threads·X·Facebook의 공개 단일 영상 게시물을 지원합니다.
프로필·목록·단축 공유 링크는 지원하지 않습니다.
목록 전체 다운로드, 실시간 방송, 비공개·유료·DRM 영상은 지원하지 않습니다.
본인 소유 또는 다운로드 허가를 받은 영상에 사용하세요.
유튜브의 서비스 변경이나 지역·계정·네트워크 제한으로 일부 링크는 실패할 수
있습니다. 이 경우 표시되는 오류와 ‘작업 기록’을 확인하세요.
브라우저 쿠키나 로그인 정보를 자동으로 읽지 않습니다.

파일 구성
Sources/         앱 화면과 다운로드 엔진의 Swift 소스
Tools/           공식 yt-dlp 실행 파일, 무결성 확인 자료와 라이선스
Tests/           검증 코드와 결과
build_app.py     앱 빌드 및 도구 묶음 생성 스크립트
THIRD_PARTY_NOTICES.md   포함된 외부 도구 안내

실행 환경
현재 Mac의 Apple Silicon 및 macOS 26 이상에 맞춰 제작했습니다.
다운로드 시 인터넷 연결이 필요합니다.
앱에는 yt-dlp, FFmpeg/FFprobe, Node 실행 도구가 포함됩니다.
이 Mac 앱은 개인용 프로그램입니다. 함께 제공된 clipsave 웹사이트는
../HTML버전/웹버전실행.command로 실행하며, 웹 서버 배포 방법은
../HTML버전/서버배포안내.txt를 확인하세요.

개발 및 재빌드
이 폴더에서 python3 build_app.py 를 실행하면 build/Vitract.app이 생성됩니다.
재빌드에는 Xcode Command Line Tools 및 빌드 스크립트가 참조하는 개발용
FFmpeg, FFprobe, Node가 필요합니다. 이미 완성된 실행 앱에는 필요하지 않습니다.
외부 배포를 할 경우 포함 도구들의 라이선스 및 서명/공증 조건을 확인해야 합니다.

디자인
빨간 둥근 사각형과 흰 재생 삼각형을 참고한 독자 아이콘입니다.
YouTube/Google의 공식 앱 또는 제휴 서비스가 아닙니다.


스크립트 추출 (2026-10-26 추가)
영상 확인 → 자막 언어 선택 → 스크립트 저장 (TXT).
영상 파일을 다운로드하지 않고 제작자 자막 또는 자동 생성 자막을 텍스트로 저장합니다.
저장 위치는 MP4와 동일한 선택 폴더이며, 같은 이름은 번호를 붙여 보존합니다.
자막이 없는 영상의 음성 인식은 현재 지원하지 않습니다. 자동 자막은 오인식이 있을 수 있습니다.
