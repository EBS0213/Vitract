clipsave 시작하기

clipsave는 링크 하나를 확인하고 MP4를 바로 내려받는 웹사이트입니다.
개인 작업 기록이나 영상 보관함을 제공하지 않습니다.

1. ‘웹버전실행.command’를 더블클릭합니다.
2. 터미널이 열리면 브라우저에서 http://127.0.0.1:8766 을 엽니다.
3. Instagram / Threads / X / Facebook / YouTube를 선택하고 개별 영상 링크를 넣습니다.
   ‘Inspect’를 누른 뒤 ‘Quality’에서 화질을 선택합니다.
4. 준비가 끝나면 브라우저 다운로드를 한 번 시도합니다. 브라우저가 자동 다운로드를
   막았거나 파일을 다시 받아야 하면 화면의 ‘Download’를 누르세요.

작업 중 터미널을 열어 두고 종료하려면 Control+C를 누릅니다.
화면을 새로고침하거나 닫으면 현재 작업 표시가 초기화됩니다. 브라우저 저장소에
작업 기록을 남기거나 과거 작업을 복원하지 않습니다. 브라우저의 다운로드 목록과
실제로 받은 파일은 브라우저가 관리합니다.

index.html 직접 더블클릭은 디자인·실행 안내를 보기 위한 것입니다.
file:// 주소에서는 다운로드 처리가 되지 않으므로 실행기로 서버를 열어 주세요.
Python 3.10 이상이 필요하고 첫 실행에 웹 서버 패키지가 없으면 전용 .venv에
설치합니다. 이때 인터넷 연결이 필요합니다. 함께 제공된 Mac 앱의 도구를 우선 씁니다.

수동 실행
  python3 launch.py
  python3 launch.py --port 8767
  python3 server.py --host 127.0.0.1 --port 8766 --data-dir ./data

기본 로컬 실행은 이 컴퓨터에서만 접속됩니다. 공개 배포는 서버배포안내.txt를
따르세요. 기본 Docker 구성은 PUBLIC_MODE=1로 비밀번호 없이 이용하는 공개 모드이며
접속 주소 확인, 세션별 작업 소유권, IP별 요청 제한을 적용합니다.

폴더
  문서 / 영상제작 APP / HTML버전 : clipsave 웹 코드와 안내문
  문서 / 영상제작 APP / macOS버전 : 기존 ‘영상저장’ Mac 앱
  문서 / 영상제작 APP / 영상저장.app : 기존 Mac 앱 바로가기
  HTML버전/dist/clipsave_웹배포.zip : 서버 배포용 소스 ZIP

서버의 data 폴더에는 처리에 필요한 임시 파일·작업·세션만 보관합니다.
완료·실패·취소 후 1시간이 지나면 임시 작업과 파일을 정리합니다. 브라우저 쿠키는
브라우저 세션용이고 서버에서 2시간 후 만료됩니다. 브라우저 설정에 따라 세션 쿠키가
복원될 수 있어도 개인 기록 화면은 제공하지 않습니다. 파일은 완료 후 바로 받으세요.
비밀번호나 쿠키가 바뀌면 이전 작업 파일에 접근할 수 없습니다.

선택한 화질은 최대 높이이며 원본을 확대하지 않습니다. MP4의 H.264/yuv420p 영상,
소리가 있으면 AAC 소리, faststart 구조를 검사합니다. YouTube 개별 영상/Shorts,
Instagram 개별 동영상/Reels, Threads 공개 단일 동영상, X 단일 동영상 게시물,
Facebook 동영상/Reels의 원본 링크를 지원합니다. 선택한 플랫폼과 링크가 일치해야 합니다.
Threads는 공개 임베드 페이지에서 제공되는 단일 MP4만 처리합니다.
재생목록·여러 영상/사진 캐러셀·실시간·예정 방송·로그인이나 권한이 필요한 영상은
지원하지 않습니다. 공유용 단축 링크 대신 원본 게시물 주소를 사용하세요.
사이트 변경·IP·지역·요청 제한에 따라 공개 영상도 실패할 수 있습니다.
본인에게 저장할 권한이 있는 영상을 이용해 주세요.

화면 좌우는 광고 배치 자리입니다. 실제 AdSense 계정 ID와 광고 스크립트는 들어 있지
않습니다. 광고 연결 전에는 광고영역안내.txt와 CSP 설정을 확인하세요.
